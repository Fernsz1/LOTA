# LOTA

fighting game

## Controls

Each player can use a keyboard or a gamepad. Gamepad device 0 maps to Player 1,
device 1 to Player 2.

| Action | Player 1 (keyboard) | Player 2 (keyboard) | Gamepad |
| --- | --- | --- | --- |
| Move up | W | ↑ | D-pad Up |
| Move down | S | ↓ | D-pad Down |
| Move left | A | ← | D-pad Left |
| Move right | D | → | D-pad Right |
| Fast | C | J | A (bottom) |
| Heavy | V | K | X (left) |
| Skill | B | L | B (right) |
| Ultimate | F | I | Y (top) |

### Debug

| Action | Key |
| --- | --- |
| Toggle hit/hurt boxes | F1 |
